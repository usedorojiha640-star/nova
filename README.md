# QuickX NOVA — отдельный проект

Независимый сайт QuickX с новым дизайном. Он не заменяет действующий quickx.club. Для публикации используйте отдельный GitHub-репозиторий и отдельный Cloudflare-проект.

## Запуск

Требуется Node.js 20.19+.

```bash
npm install
npm run dev
```

Откройте адрес, указанный Vite (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
```

Файлы публикации будут в `dist`. Для Cloudflare Pages используйте команду `npm run build` и output directory `dist`. При подключении Cloudflare Workers Static Assets настройте сборку согласно выбранному способу деплоя.

## Контакты

Менеджерская ссылка хранится в `src/config.js` в переменной `MANAGER_URL` и используется во всех кнопках сайта. Это внешний адрес-переход, проверьте его назначение перед публикацией.

## Особенности

- React и Vite; нет внешних UI-библиотек.
- Мобильное меню, FAQ, интерактивный выбор направления и актива, копирование запроса.
- Иллюстрации и география являются оформлением; цены, курсы и наличие офисов не утверждаются.
- Яркий стиль: electric blue, aqua, violet, coral; поддержка `prefers-reduced-motion`.
- Ни API, ни кошельков, ни приёма средств на сайте нет.
